    Worksheet Activity 2.6.4

    Activity 36.

    In this activity, we will use homogeneous coordinates and matrix transformations to move our character into a variety of poses.
    🔗
    1. Since we regard our character as living in \(\real^3\text{,}\) we will consider matrix transformations defined by matrices
      \begin{equation*} \left[\begin{array}{rrr} a \amp b \amp c \\ d \amp e \amp f \\ 0 \amp 0 \amp 1 \\ \end{array}\right]\text{.} \end{equation*}
      Verify that such a matrix transformation transforms points in the plane \(z=1\) into points in the same plane; that is, verify that
      \begin{equation*} \left[\begin{array}{rrr} a \amp b \amp c \\ d \amp e \amp f \\ 0 \amp 0 \amp 1 \\ \end{array}\right] \threevec{x}{y}{1} = \threevec{x'}{y'}{1}\text{.} \end{equation*}
      Express the coordinates of the resulting point \(x'\) and \(y'\) in terms of the coordinates of the original point \(x\) and \(y\text{.}\)
      🔗
      🔗
    2. Find the matrix transformation that translates our character to a new position in the plane, as shown in Figure 21
      🔗
      🔗
    3. As originally drawn, our character is waving with one of their hands. In one of the movie’s scenes, we would like them to wave with their other hand, as shown in Figure 22. Find the matrix transformation that moves them into this pose.
      🔗
      🔗
    4. Later, our character performs a cartwheel by moving through the sequence of poses shown in Figure 23. Find the matrix transformations that create these poses.
      🔗
      🔗
    5. Next, we would like to find the transformations that zoom in on our character’s face, as shown in Figure 24. To do this, you should think about composing matrix transformations. This can be accomplished in the diagram by using the Compose button, which makes the current pose, displayed on the right, the new beginning pose, displayed on the left. What is the matrix transformation that moves the character from the original pose, shown in the upper left, to the final pose, shown in the lower right?
      🔗
      🔗
    6. We would also like to create our character’s shadow, shown in the sequence of poses in Figure 25. Find the sequence of matrix transformations that achieves this. In particular, find the matrix transformation that takes our character from their original pose to their shadow in the lower right.
      🔗
      🔗
    7. Write a final scene to the movie and describe how to construct a sequence of matrix transformations that create your scene.
      🔗
      🔗
    🔗
    Solution.
    1. \begin{equation*} \left[\begin{array}{rrr} a \amp b \amp c \\ d \amp e \amp f \\ 0 \amp 0 \amp 1 \\ \end{array}\right] \threevec{x}{y}{1} = \cthreevec{ax+by+c}{dx+ey+f}{1}\text{,} \end{equation*}
      which shows that
      \begin{equation*} \begin{alignedat}{2} x' \amp {}={} ax+by+c \\ y' \amp {}={} dx+ey+f\text{.} \\ \end{alignedat} \end{equation*}
      🔗
      🔗
    2. Notice that the entries \(c\) and \(f\) are responsible for the translation. Therefore, we need the matrix transformation defined by \(\left[\begin{array}{rrr} 1 \amp 0 \amp 2 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp 1 \\ \end{array}\right] \text{.}\)
      🔗
      🔗
    3. We would like to reflect in the vertical axis so we use the matrix \(\left[\begin{array}{rrr} -1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \\ \end{array}\right] \text{.}\)
      🔗
      🔗
    4. The character is successively rotated by \(45^\circ\) using the matrix \(\left[\begin{array}{rrr} \cos(45^\circ) \amp -\sin(45^\circ) \amp 0 \\ \sin(45^\circ) \amp \sin(45^\circ) \amp 0 \\ 0 \amp 0 \amp 1 \\ \end{array}\right] = \left[\begin{array}{rrr} \frac{1}{\sqrt{2}} \amp -\frac{1}{\sqrt{2}} \amp 0 \\ \frac{1}{\sqrt{2}} \amp \frac{1}{\sqrt{2}} \amp 0 \\ 0 \amp 0 \amp 1 \\ \end{array}\right] \text{.}\)
      🔗
      🔗
    5. We first translate the character down two units using the matrix \(\left[\begin{array}{rrr} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp -2 \\ 0 \amp 0 \amp 1 \\ \end{array}\right] \text{.}\) Then we zoom in by uniformly stretching by a factor of \(2\) using the matrix \(\left[\begin{array}{rrr} 2 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 1 \\ \end{array}\right] \text{.}\) The net effect is the transformation described by the matrix
      \begin{equation*} \left[\begin{array}{rrr} 2 \amp 0 \amp 0 \\ 0 \amp 2 \amp 0 \\ 0 \amp 0 \amp 1 \\ \end{array}\right] \left[\begin{array}{rrr} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp -2 \\ 0 \amp 0 \amp 1 \\ \end{array}\right] = \left[\begin{array}{rrr} 2 \amp 0 \amp 0 \\ 0 \amp 2 \amp -4 \\ 0 \amp 0 \amp 1 \\ \end{array}\right]\text{.} \end{equation*}
      🔗
      🔗
    6. The shadow is first created using the shear \(\left[\begin{array}{rrr} 1 \amp 1 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \\ \end{array}\right] \text{.}\) Then the vertical scale is compressed using the matrix \(\left[\begin{array}{rrr} 1 \amp 0 \amp 0 \\ 0 \amp \frac12 \amp 0 \\ 0 \amp 0 \amp 1 \\ \end{array}\right] \text{.}\)
      🔗
