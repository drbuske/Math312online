    Exercises Questions

    1.
    Let \(V\) be the set of all real sequences
    \begin{equation*} (x_1,x_2,x_3,\dots) \end{equation*}
    such that \(x_n \ge 0\) for all \(n\text{.}\) Use the usual definitions of addition and scalar multiplication of sequences. Determine whether \(V\) is a vector space over \(\mathbb{R}\text{.}\)
    🔗
    Hint.
    Think about additive inverses.
    🔗
    🔗
    Answer.
    \(V\) is not a vector space.
    🔗
    🔗
    Solution.
    The zero sequence belongs to \(V\text{,}\) and \(V\) is closed under addition. However, if \(\mathbf{x}\in V\) and \(\mathbf{x}\neq\mathbf{0}\text{,}\) then \(-\mathbf{x}\) has negative entries and does not belong to \(V\text{.}\)
    🔗
    Thus additive inverses do not exist for all vectors, so axiom (A4) fails and \(V\) is not a vector space.
    🔗
    🔗
    🔗
    2.
    Let \(V=\mathbb{R}^2\text{.}\) Define addition as usual, but define scalar multiplication by
    \begin{equation*} c \odot (x,y) = (cx, |c|y). \end{equation*}
    Determine whether \((V,+,\odot)\) is a vector space.
    🔗
    Hint.
    Check whether \((-1)\odot(( -1)\odot\mathbf{v})\) behaves as expected.
    🔗
    🔗
    Answer.
    \(V\) is not a vector space.
    🔗
    🔗
    Solution.
    Let \(\mathbf{v}=(0,1)\text{.}\) Then \((-1)\odot\mathbf{v}=(0,1)\text{,}\) since \(|-1|=1\text{.}\)
    🔗
    But \((-1)(-1)\odot\mathbf{v} = 1\odot\mathbf{v}=(0,1)\text{,}\) while associativity of scalar multiplication requires \((-1)((-1)\odot\mathbf{v}) = (1)\odot\mathbf{v}\) to equal \((-1\cdot-1)\odot\mathbf{v}\) for all vectors.
    🔗
    The scalar multiplication axiom (SM3) fails, so \(V\) is not a vector space.
    🔗
    🔗
    🔗
    3.
    Let \(V\) be the set of all real polynomials. Define addition as usual, but define scalar multiplication by
    \begin{equation*} c \odot p(x) = cp(x) + (1-c). \end{equation*}
    Determine whether \((V,+,\odot)\) is a vector space.
    🔗
    Hint.
    Identify the additive identity and test scalar distributivity.
    🔗
    🔗
    Answer.
    \(V\) is not a vector space.
    🔗
    🔗
    Solution.
    The additive identity with respect to usual addition is the zero polynomial, but \(c\odot 0 = 1-c\text{,}\) which is not the zero polynomial unless \(c=1\text{.}\)
    🔗
    Thus scalar multiplication does not preserve the additive identity, violating axiom (SM4). Therefore \(V\) is not a vector space.
    🔗
    🔗
    🔗
    4.
    Let \(\mathbb{P}_2\) be the vector space of all real polynomials of degree at most \(2\text{.}\) Let \(W\) be the subset of \(\mathbb{P}_2\) consisting of those polynomials \(p\) that satisfy the condition
    \begin{equation*} p'(0) + p(1) = 0. \end{equation*}
    1. What is the dimension of \(W\text{?}\)
      🔗
      🔗
    2. Find a basis for \(W\text{.}\)
      🔗
      🔗
    🔗
    Hint.
    Write a general polynomial \(p(x) = ax^2 + bx + c\text{.}\) Compute \(p'(x)\text{,}\) then evaluate \(p'(0)\) and \(p(1)\text{.}\) The given condition gives a linear equation relating \(a\text{,}\) \(b\text{,}\) and \(c\text{.}\)
    🔗
    🔗
    Answer.
    The dimension of \(W\) is \(2\text{.}\) One possible basis for \(W\) is
    \begin{equation*} \{x^2 - 1,\; x - 2\}. \end{equation*}
    🔗
    🔗
    Solution.
    Let \(p(x) = ax^2 + bx + c\) be an arbitrary element of \(\mathbb{P}_2\text{.}\) Then \(p'(x) = 2ax + b\text{,}\) so
    \begin{equation*} p'(0) = b. \end{equation*}
    Also,
    \begin{equation*} p(1) = a + b + c. \end{equation*}
    The condition \(p'(0) + p(1) = 0\) gives
    \begin{equation*} b + (a + b + c) = 0, \end{equation*}
    which simplifies to
    \begin{equation*} a + 2b + c = 0. \end{equation*}
    🔗
    Solving for \(c\text{,}\) we obtain
    \begin{equation*} c = -a - 2b. \end{equation*}
    Therefore every polynomial in \(W\) has the form
    \begin{equation*} p(x) = a(x^2 - 1) + b(x - 2). \end{equation*}
    🔗
    This shows that \(W\) is spanned by the polynomials \(x^2 - 1\) and \(x - 2\text{.}\) Since these polynomials are linearly independent, they form a basis for \(W\text{.}\) Hence
    \begin{equation*} \dim W = 2. \end{equation*}
    🔗
    🔗
    🔗
    5.
    Let \(V\) be the vector space of all real sequences
    \begin{equation*} (x_1, x_2, x_3, \dots) \end{equation*}
    with addition and scalar multiplication defined componentwise.
    🔗
    Define
    \begin{equation*} W = \{ \mathbf{x} \in V : x_{n+1} - x_n \text{ is constant for all } n \ge 1 \}. \end{equation*}
    1. Show that \(W\) is a subspace of \(V\text{.}\)
      🔗
      🔗
    2. Describe all sequences in \(W\) explicitly.
      🔗
      🔗
    3. Find a spanning set for \(W\) and determine the dimension of \(W\text{.}\)
      🔗
      🔗
    🔗
    Hint.
    If the difference \(x_{n+1} - x_n\) is constant, try rewriting \(x_{n+1}\) in terms of \(x_n\text{.}\) Think about how many initial values determine an entire sequence in \(W\text{.}\)
    🔗
    🔗
    Answer.
    The set \(W\) is a subspace of \(V\text{.}\) Every sequence in \(W\) has the form
    \begin{equation*} x_n = a + (n-1)c \end{equation*}
    for real numbers \(a\) and \(c\text{.}\) A spanning set for \(W\) is
    \begin{equation*} \{(1,1,1,\dots),(0,1,2,3,\dots)\} \end{equation*}
    and \(\dim W = 2\text{.}\)
    🔗
    🔗
    Solution.
    The zero sequence \((0,0,0,\dots)\) satisfies \(0 - 0 = 0\) for all \(n\text{,}\) so \(\mathbf{0} \in W\text{.}\)
    🔗
    Let \(\mathbf{x}, \mathbf{y} \in W\text{.}\) Then there exist constants \(c\) and \(d\) such that \(x_{n+1} - x_n = c\) and \(y_{n+1} - y_n = d\) for all \(n\text{.}\) Then
    \begin{equation*} (x+y)_{n+1} - (x+y)_n = (x_{n+1}-x_n) + (y_{n+1}-y_n) = c + d, \end{equation*}
    which is constant. Hence \(\mathbf{x} + \mathbf{y} \in W\text{.}\)
    🔗
    For any scalar \(\alpha\text{,}\)
    \begin{equation*} (\alpha x)_{n+1} - (\alpha x)_n = \alpha(x_{n+1} - x_n) = \alpha c, \end{equation*}
    which is constant. Thus \(\alpha \mathbf{x} \in W\text{.}\) Therefore, \(W\) is a subspace of \(V\text{.}\)
    🔗
    If \(\mathbf{x} \in W\text{,}\) then there exists a constant \(c\) such that \(x_{n+1} = x_n + c\) for all \(n\text{.}\) Since we also have \(x_{n}=x_{n-1} + c\text{,}\) we also know that
    \begin{align*} x_{n+1} \amp = (x_{n-1} + c)+c \\ \amp =x_{n-1}+2c. \end{align*}
    Likewise, we have that
    \begin{equation*} x_{n+1}=x_{n-2}+3c \end{equation*}
    and we conclude the pattern with
    \begin{equation*} x_n = x_1 + (n-1)c. \end{equation*}
    Hence every sequence in \(W\) is an arithmetic sequence.
    🔗
    Any \(\mathbf{x} \in W\) can be written as
    \begin{equation*} \mathbf{x} = x_1(1,1,1,\dots) + c(0,1,2,3,\dots). \end{equation*}
    Therefore,
    \begin{equation*} W = \operatorname{span}\{(1,1,1,\dots),(0,1,2,3,\dots)\}. \end{equation*}
    These two sequences are linearly independent, so \(\dim W = 2\text{.}\)
    🔗
    🔗
    🔗
    6.
    Let \(V = M_{2,2}(\mathbb{R})\) and define operations \(\oplus\) and \(\odot\) on \(V\) by
    \begin{align*} A \oplus B \amp = A + B - I, \\ c \odot A \amp = cA + (1-c)I. \end{align*}
    Show that \((V,\oplus,\odot)\) is a vector space over \(\mathbb{R}\text{.}\) Your justification should address the vector space axioms.
    🔗
    Hint.
    First identify the additive identity with respect to \(\oplus\text{.}\) Then determine the additive inverse of a general matrix \(A\text{.}\) Finally, check carefully how scalar multiplication interacts with addition.
    🔗
    🔗
    Answer.
    Yes, \((V,\oplus,\odot)\) is a vector space. The additive identity is \(I\text{,}\) the additive inverse of \(A\) is \(2I-A\text{,}\) and all vector space axioms are satisfied.
    🔗
    🔗
    Solution.
    We verify the vector space axioms. Since \(M_{2,2}(\mathbb{R})\) is closed under ordinary matrix addition and scalar multiplication, and since \(I \in V\text{,}\) the set \(V\) is closed under \(\oplus\) and \(\odot\text{.}\)
    🔗
    To find the additive identity, suppose \(Z \in V\) satisfies \(A \oplus Z = A\) for all \(A \in V\text{.}\) Then
    \begin{equation*} A + Z - I = A, \end{equation*}
    which implies \(Z = I\text{.}\) Thus the additive identity with respect to \(\oplus\) is \(I\text{.}\)
    🔗
    Let \(A \in V\text{.}\) To find the additive inverse of \(A\text{,}\) we seek \(B \in V\) such that \(A \oplus B = I\text{.}\) This gives
    \begin{equation*} A + B - I = I, \end{equation*}
    so
    \begin{equation*} B = 2I - A. \end{equation*}
    Hence every element of \(V\) has an additive inverse.
    🔗
    The operation \(\oplus\) is commutative and associative because ordinary matrix addition is commutative and associative, and the same matrix \(I\) is subtracted in every sum.
    🔗
    We now verify compatibility of scalar multiplication. Let \(c,d \in \mathbb{R}\) and \(A \in V\text{.}\) Then
    \begin{align*} c \odot (d \odot A) \amp = c \odot (dA + (1-d)I) \\ \amp = cdA + c(1-d)I + (1-c)I \\ \amp = (cd)A + (1-cd)I \\ \amp = (cd) \odot A. \end{align*}
    🔗
    We also check distributivity over addition. For \(A,B \in V\text{,}\)
    \begin{align*} c \odot (A \oplus B) \amp = c \odot (A + B - I) \\ \amp = cA + cB - cI + (1-c)I \\ \amp = cA + cB +I - 2cI, \end{align*}
    while
    \begin{align*} (c \odot A) \oplus (c \odot B) \amp = (cA + (1-c)I) + (cB + (1-c)I) - I \\ \amp = cA + cB +I - 2cI. \end{align*}
    Thus scalar multiplication distributes over addition.
    🔗
    Finally,
    \begin{equation*} 1 \odot A = 1A + (1-1)I = A, \end{equation*}
    so the scalar identity axiom holds. Therefore all vector space axioms are satisfied, and \((V,\oplus,\odot)\) is a vector space.
    🔗
    🔗
    🔗
    7.
    Let \(V\) be a vector space and let \(S=\{\mathbf{v}_1,\mathbf{v}_2,\mathbf{v}_3,\mathbf{v}_4\}\subseteq V\text{.}\) Suppose that
    \begin{equation*} \mathbf{v}_4=\mathbf{v}_1+\mathbf{v}_2 \end{equation*}
    and that the set \(\{\mathbf{v}_1,\mathbf{v}_2,\mathbf{v}_3\}\) is linearly independent. Find a basis for \(\operatorname{span}(S)\text{.}\)
    🔗
    Hint.
    Decide whether \(\mathbf{v}_4\) adds anything new to the span.
    🔗
    🔗
    Answer.
    A basis for \(\operatorname{span}(S)\) is \(\{\mathbf{v}_1,\mathbf{v}_2,\mathbf{v}_3\}\text{.}\)
    🔗
    🔗
    Solution.
    Since \(\mathbf{v}_4\) is a linear combination of \(\mathbf{v}_1\) and \(\mathbf{v}_2\text{,}\) it does not add anything new to the span.
    🔗
    Because \(\{\mathbf{v}_1,\mathbf{v}_2,\mathbf{v}_3\}\) is already linearly independent and spans the same space, it is a basis for \(\operatorname{span}(S)\text{.}\)
    🔗
    🔗
    🔗
    8.
    Let \(V=\mathbb{R}^n\text{,}\) and let \(A\) be a fixed \(n\times n\) real matrix. Define
    \begin{equation*} S = \{\mathbf{x}\in\mathbb{R}^n : A\mathbf{x} = 2\mathbf{x}\}. \end{equation*}
    Determine whether \(S\) is a subspace of \(\mathbb{R}^n\text{.}\) Justify your answer.
    🔗
    Hint.
    Suppose \(\mathbf{x}_1\) and \(\mathbf{x}_2\) satisfy \(A\mathbf{x}=2\mathbf{x}\text{.}\) Check whether their sum and scalar multiples also satisfy this condition.
    🔗
    🔗
    Answer.
    Yes, \(S\) is a subspace of \(\mathbb{R}^n\text{.}\)
    🔗
    🔗
    Solution.
    Let \(\mathbf{x}_1,\mathbf{x}_2\in S\text{.}\) Then \(A\mathbf{x}_1=2\mathbf{x}_1\) and \(A\mathbf{x}_2=2\mathbf{x}_2\text{.}\) Using linearity of matrix multiplication,
    \begin{equation*} A(\mathbf{x}_1+\mathbf{x}_2) = A\mathbf{x}_1 + A\mathbf{x}_2 = 2\mathbf{x}_1 + 2\mathbf{x}_2 = 2(\mathbf{x}_1+\mathbf{x}_2). \end{equation*}
    Thus \(\mathbf{x}_1+\mathbf{x}_2\in S\text{,}\) so \(S\) is closed under addition.
    🔗
    Let \(c\in\mathbb{R}\) and let \(\mathbf{x}_1\in S\text{.}\) Then
    \begin{equation*} A(c\mathbf{x}_1) = cA\mathbf{x}_1 = c(2\mathbf{x}_1) = 2(c\mathbf{x}_1), \end{equation*}
    so \(c\mathbf{x}_1\in S\text{.}\) Thus \(S\) is closed under scalar multiplication.
    🔗
    Since \(A\mathbf{0}=2\mathbf{0}\text{,}\) the zero vector belongs to \(S\text{.}\) Therefore \(S\) is a subspace of \(\mathbb{R}^n\text{.}\)
    🔗
    Note that the vectors in \(S\) are eigenvectors of \(A\) with eigenvalue \(2\text{.}\)
    🔗
    🔗
    🔗
    9.
    Let \(V = F(-\infty,\infty)\) be the vector space of all real‑valued functions defined on \((-\infty,\infty)\text{.}\) Define
    \begin{equation*} S = \{ f \in V : f(x) = a\cos x + b\sin x + c \text{ for some } a,b,c \in \mathbb{R} \}. \end{equation*}
    Determine whether \(S\) is a subspace of \(V\text{.}\) Justify your answer.
    🔗
    Hint.
    Write two generic functions in \(S\) and compute their sum. Then check what happens when you multiply such a function by a scalar.
    🔗
    🔗
    Answer.
    Yes, \(S\) is a subspace of \(V\text{.}\)
    🔗
    🔗
    Solution.
    Let \(f\) and \(g\) be functions in \(S\text{.}\) Then there exist real numbers \(a_1,b_1,c_1\) and \(a_2,b_2,c_2\) such that
    \begin{equation*} f(x)=a_1\cos x + b_1\sin x + c_1 \quad \text{and} \quad g(x)=a_2\cos x + b_2\sin x + c_2. \end{equation*}
    🔗
    Their sum is
    \begin{equation*} f(x)+g(x) = (a_1+a_2)\cos x + (b_1+b_2)\sin x + (c_1+c_2), \end{equation*}
    which is again of the same form. Thus \(S\) is closed under addition.
    🔗
    Let \(r \in \mathbb{R}\text{.}\) Then
    \begin{equation*} r f(x) = (r a_1)\cos x + (r b_1)\sin x + (r c_1), \end{equation*}
    which is also of the required form. Hence \(S\) is closed under scalar multiplication.
    🔗
    The zero function belongs to \(S\) by taking \(a=b=c=0\text{.}\) Therefore \(S\) contains the zero vector.
    🔗
    Since \(S\) contains the zero function and is closed under addition and scalar multiplication, it is a subspace of \(V\text{.}\)
    🔗
    🔗
    🔗
    10.
    Find the dimension of \(\mathcal{Z}_2\text{,}\) the vector space of all \(2\times 2\) real matrices with zero trace. Note: The trace is defined as the sum of the diagonal elements of a matrix.
    🔗
    Hint.
    Write a general \(2\times 2\) matrix, impose the zero‑trace condition, and count how many free parameters remain.
    🔗
    🔗
    Answer.
    The dimension is \(3\text{.}\)
    🔗
    🔗
    Solution.
    A general \(2\times 2\) real matrix has the form \(\begin{bmatrix} a \amp b \\ c \amp d \end{bmatrix}\text{.}\) The trace is \(a+d\text{.}\)
    🔗
    The condition that the trace is zero gives \(a+d=0\text{,}\) or \(d=-a\text{.}\) Thus every matrix in \(\mathcal{Z}_2\) can be written as \(\begin{bmatrix} a \amp b \\ c \amp -a \end{bmatrix}\text{.}\)
    🔗
    The entries \(a\text{,}\) \(b\text{,}\) and \(c\) are free, so the space depends on three independent real parameters. Therefore \(\dim(\mathcal{Z}_2)=3\text{.}\)

    11.
    Let \(\mathcal{U}\) be the set of all \(2\times2\) real matrices of the form
    \begin{equation*} \begin{bmatrix} u \amp -u-x \\ 0 \amp x \end{bmatrix}, \end{equation*}
    where \(u,x \in \mathbb{R}\text{,}\) and let \(\mathcal{V}\) be the set of all \(2\times2\) real matrices of the form
    \begin{equation*} \begin{bmatrix} v \amp 0 \\ w \amp -v \end{bmatrix}, \end{equation*}
    where \(v,w \in \mathbb{R}\text{.}\)
    🔗
    Find a basis for \(\mathcal{U}\) and \(\mathcal{V}\text{.}\)
    🔗
    Hint.
    Write a general element of each set as a linear combination of matrices involving one parameter at a time.
    🔗
    🔗
    Answer.
    A basis for \(\mathcal{U}\) is
    \begin{equation*} \left\{ \begin{bmatrix}1\amp -1\\0\amp 0\end{bmatrix}, \begin{bmatrix}0\amp -1\\0\amp 1\end{bmatrix} \right\}. \end{equation*}
    A basis for \(\mathcal{V}\) is
    \begin{equation*} \left\{ \begin{bmatrix}1\amp 0\\0\amp -1\end{bmatrix}, \begin{bmatrix}0\amp 0\\1\amp 0\end{bmatrix} \right\}. \end{equation*}
    🔗
    🔗
    Solution.
    Any matrix in \(\mathcal{U}\) can be written as
    \begin{equation*} u\begin{bmatrix}1\amp -1\\0\amp 0\end{bmatrix} + x\begin{bmatrix}0\amp -1\\0\amp 1\end{bmatrix}. \end{equation*}
    These two matrices are linearly independent, so they form a basis for \(\mathcal{U}\text{.}\)
    🔗
    Any matrix in \(\mathcal{V}\) can be written as
    \begin{equation*} v\begin{bmatrix}1\amp 0\\0\amp -1\end{bmatrix} + w\begin{bmatrix}0\amp 0\\1\amp 0\end{bmatrix}. \end{equation*}
    These matrices are linearly independent, so they form a basis for \(\mathcal{V}\text{.}\)

    12. Linear Independence and Dimension.
    Let \(V\) be a vector space with \(\dim V = 12\text{.}\) Let \(S\) be a subset of \(V\) that is linearly independent and has \(11\) vectors. Which of the following statements is false?
    🔗
    • There must exist a linearly independent subset \(S_1\) of \(V\) such that \(S \subseteq S_1\) and \(S_1\) is not a basis for \(V\text{.}\)
    • Every nonempty subset \(S_1\) of \(S\) is linearly independent.
    • There must exist a linearly dependent subset \(S_1\) of \(V\) such that \(S \subseteq S_1\text{.}\)
    • \(\dim(\operatorname{span}(S)) < \dim V\text{.}\)

    13. Linear Dependence of Matrix Powers.
    Let \(A\) be a \(5\times5\) matrix with real entries and let \(\mathbf{x}\neq\mathbf{0}\text{.}\) Consider the vectors
    \begin{equation*} \mathbf{x},\; A\mathbf{x},\; A^2\mathbf{x},\; A^3\mathbf{x},\; A^4\mathbf{x},\; A^5\mathbf{x}. \end{equation*}
    Which of the following statements is correct?
    🔗
    • The vectors are linearly independent.
    • A vector space of dimension \(5\) cannot contain six linearly independent vectors.
    • The vectors are linearly dependent.
    • A nontrivial linear combination of \(\mathbf{x},A\mathbf{x},\dots,A^5\mathbf{x}\) equal to \(\mathbf{0}\text{.}\)
    • The vectors are linearly independent if and only if \(A\) is symmetric.
    • Symmetry of \(A\) has no bearing on linear dependence of these vectors.
    • Linear dependence or independence cannot be determined from the given data.
    • Linear dependence occurs regardless of the choice of \(A\) and \(\mathbf{x}\text{.}\)
