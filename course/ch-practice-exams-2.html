    Exercises Questions

    1.
    Consider the equation \(2x - y = 3\text{.}\)
    🔗
    1. How many solutions does this equation have?
      🔗
    2. Give a geometric interpretation of the solution set.
      🔗
    Hint.
    Think about what the graph of a single linear equation in two unknowns looks like.
    🔗
    🔗
    Answer.
    1. Infinitely many solutions.
      🔗
    2. The solution set is a line in the plane.
      🔗
    🔗
    Solution.
    A single linear equation in two unknowns represents a line in the coordinate plane. Every point on this line satisfies the equation, so there are infinitely many solutions.
    🔗
    🔗
    🔗
    2.
    Consider the system of equations
    \begin{equation*} \begin{aligned} x + y \amp= 4 \\ x - y \amp= 2 \end{aligned} \end{equation*}
    🔗
    1. How many solutions does this system have?
      🔗
    2. Explain your answer geometrically.
      🔗
    Hint.
    Think about how two non‑parallel lines intersect.
    🔗
    🔗
    Answer.
    1. Exactly one solution.
      🔗
    2. The lines intersect at a single point.
      🔗
    🔗
    Solution.
    Each equation represents a line in the plane. Since the lines are not parallel, they intersect in exactly one point. That point satisfies both equations, so the system has exactly one solution.
    🔗
    🔗
    🔗
    3.
    Consider the system
    \begin{equation*} \begin{aligned} 2x + y \amp= 1 \\ 2x + y \amp= 3 \end{aligned} \end{equation*}
    🔗
    1. Does this system have a solution?
      🔗
      🔗
    2. Explain why or why not.
      🔗
      🔗
    Hint.
    Compare the two equations and think about their graphs.
    🔗
    🔗
    Answer.
    1. No.
      🔗
      🔗
    2. The equations represent parallel lines.
      🔗
      🔗
    🔗
    Solution.
    1. The system has no solutions.
      🔗
      🔗
    2. The equations have the same left‑hand side but different constants, so they represent distinct parallel lines, which do not intersect.
      🔗
      🔗
    🔗
    🔗
    4.
    Consider the system
    \begin{equation*} \begin{aligned} x + y \amp= 2 \\ x - y \amp= 0 \\ 2x \amp= 4 \end{aligned} \end{equation*}
    🔗
    How many solutions does this system have? Explain your reasoning.
    🔗
    Hint.
    Think about whether all three equations can be satisfied at the same time.
    🔗
    🔗
    Answer.
    Exactly one solution.
    🔗
    🔗
    Solution.
    The first two equations intersect at a single point. The third equation is also satisfied by that same point. Therefore, all three equations are satisfied by exactly one point.
    🔗
    🔗
    🔗
    5.
    Consider two linear equations in three unknowns.
    🔗
    1. What does the solution set of a single linear equation in three unknowns look like geometrically?
      🔗
      🔗
    2. What would you typically expect the solution set of two such equations to look like?
      🔗
      🔗
    Hint.
    Recall how lines generalize to higher dimensions.
    🔗
    🔗
    Answer.
    1. A plane.
      🔗
      🔗
    2. A line.
      🔗
      🔗
    🔗
    Solution.
    1. A single linear equation in three unknowns represents a plane in three‑dimensional space.
      🔗
      🔗
    2. Two planes typically intersect in a line, which forms the solution set.
      🔗
      🔗
    🔗
    🔗
    6.
    Solve the system of equations
    \begin{equation*} \begin{aligned} x + y \amp= 5 \\ x - y \amp= 1 \end{aligned} \end{equation*}
    and describe the solution set.
    🔗
    Hint.
    Try adding the two equations.
    🔗
    🔗
    Answer.
    The solution is \((x,y) = (3,2)\text{.}\)
    🔗
    🔗
    Solution.
    Adding the two equations gives \(2x = 6\text{,}\) so \(x = 3\text{.}\) Substituting into the first equation gives \(3 + y = 5\text{,}\) so \(y = 2\text{.}\) Thus the system has exactly one solution, \((3,2)\text{.}\)
    🔗
    🔗
    🔗
    7.
    Determine whether the following system is equivalent to
    \begin{equation*} \begin{aligned} x + y \amp= 4 \\ 2x + 2y \amp= 8 \end{aligned}\text{.} \end{equation*}
    Explain your reasoning.
    🔗
    \begin{equation*} \begin{aligned} x + y \amp= 4 \\ x + y \amp= 4 \end{aligned} \end{equation*}
    🔗
    Hint.
    Think about whether the two systems have the same solutions.
    🔗
    🔗
    Answer.
    Yes, the systems are equivalent.
    🔗
    🔗
    Solution.
    The second equation in the original system is just twice the first, so it does not impose a new condition. Both systems describe the same set of solutions: all points satisfying \(x + y = 4\text{.}\) Therefore, the systems are equivalent.
    🔗
    🔗
    🔗
    8.
    Consider the system
    \begin{equation*} \begin{aligned} x + y \amp= 2 \\ x + y \amp= 5 \end{aligned} \end{equation*}
    🔗
    Determine whether this system has a solution. If it does, find all solutions. If it does not, explain why.
    🔗
    Hint.
    Ask whether a single pair \((x,y)\) can satisfy both equations at the same time.
    🔗
    🔗
    Answer.
    The system has no solutions.
    🔗
    🔗
    Solution.
    The first equation requires \(x + y = 2\text{,}\) while the second requires \(x + y = 5\text{.}\) There is no pair of numbers \((x,y)\) for which both of these statements can be true simultaneously.
    🔗
    Therefore, the system is inconsistent and has no solutions.
    🔗
    🔗
    🔗
    9.
    Solve the system
    \begin{equation*} \begin{aligned} x + 2y \amp= 6 \\ 2x + 4y \amp= 12 \end{aligned} \end{equation*}
    and describe the solution set.
    🔗
    Hint.
    Compare the second equation to the first.
    🔗
    🔗
    Answer.
    The system has infinitely many solutions.
    🔗
    🔗
    Solution.
    The second equation is obtained by multiplying the first by 2, so both equations describe the same line. Every solution of \(x + 2y = 6\) satisfies both equations. Therefore, the system has infinitely many solutions.
    🔗
    🔗
    🔗
    10.
    Solve the system
    \begin{equation*} \begin{aligned} x + y + z \amp= 6 \\ x - y + z \amp= 2 \end{aligned} \end{equation*}
    and describe the solution set.
    🔗
    Hint.
    Subtract the second equation from the first.
    🔗
    🔗
    Answer.
    The solution set is a line in three‑dimensional space.
    🔗
    🔗
    Solution.
    Subtracting the second equation from the first gives \(2y = 4\text{,}\) so \(y = 2\text{.}\) Substituting into the first equation gives \(x + z = 4\text{.}\)
    🔗
    Thus the solutions are all triples of the form \((x,2,4-x)\text{.}\) Since there are infinitely many such triples, the solution set is a line.
    🔗
    🔗
    🔗
    11.
    The reduced augmented matrix of a linear system is
    \begin{equation*} \left[ \begin{array}{cc\amp c} 1 \amp 0 \amp 3 \\ 0 \amp 1 \amp -2 \end{array} \right]. \end{equation*}
    🔗
    Find the solution to the system.
    🔗
    Hint.
    Interpret each row as an equation.
    🔗
    🔗
    Answer.
    \((x,y) = (3,-2)\text{.}\)
    🔗
    🔗
    Solution.
    The first row corresponds to \(x = 3\text{,}\) and the second row corresponds to \(y = -2\text{.}\) Therefore, the unique solution is \((3,-2)\text{.}\)
    🔗
    🔗
    🔗
    12.
    Consider the augmented matrix
    \begin{equation*} \left[ \begin{array}{cc\amp c} 1 \amp 2 \amp 4 \\ 0 \amp 0 \amp 1 \end{array} \right]. \end{equation*}
    🔗
    Does the corresponding system have a solution? Explain your answer.
    🔗
    Hint.
    What equation does the second row represent?
    🔗
    🔗
    Answer.
    The system has no solutions.
    🔗
    🔗
    Solution.
    The second row represents the equation \(0 = 1\text{,}\) which is impossible. Therefore, the system is inconsistent and has no solutions.
    🔗
    🔗
    🔗
    13.
    The augmented matrix of a linear system is
    \begin{equation*} \left[ \begin{array}{cc\amp c} 1 \amp -1 \amp 2 \\ 0 \amp 0 \amp 0 \end{array} \right]. \end{equation*}
    🔗
    Describe the solution set.
    🔗
    Hint.
    Identify any free variables.
    🔗
    🔗
    Answer.
    The system has infinitely many solutions.
    🔗
    🔗
    Solution.
    The first row represents \(x - y = 2\text{,}\) and the second row imposes no additional condition. Solving for \(x\) gives \(x = y + 2\text{.}\)
    🔗
    Since \(y\) is free, there are infinitely many solutions of the form \((y+2,y)\text{.}\)
    🔗
    🔗
    🔗
    14.
    Start with the augmented matrix
    \begin{equation*} \left[ \begin{array}{cc\amp c} 1 \amp 1 \amp 5 \\ 2 \amp 3 \amp 11 \end{array} \right]. \end{equation*}
    🔗
    Replace the second row with the result of subtracting twice the first row from it. Then find the solution to the system.
    🔗
    Hint.
    Compute \(R_2 - 2R_1\text{.}\)
    🔗
    🔗
    Answer.
    \((x,y) = (2,3)\text{.}\)
    🔗
    🔗
    Solution.
    Subtracting twice the first row from the second gives
    \begin{equation*} \left[ \begin{array}{cc\amp c} 1 \amp 1 \amp 5 \\ 0 \amp 1 \amp 1 \end{array} \right]. \end{equation*}
    🔗
    The second row gives \(y = 1\text{.}\) Substituting into the first equation yields \(x = 4\text{.}\) Thus the solution is \((4,1)\text{.}\)
    🔗
    🔗
    🔗
    15.
    The reduced augmented matrix of a system in three variables is
    \begin{equation*} \left[ \begin{array}{ccc\amp c} 1 \amp 0 \amp 2 \amp 1 \\ 0 \amp 1 \amp -1 \amp 3 \end{array} \right]. \end{equation*}
    🔗
    Describe the solution set geometrically.
    🔗
    Hint.
    Count the number of free variables.
    🔗
    🔗
    Answer.
    The solution set is a line in three‑dimensional space.
    🔗
    🔗
    Solution.
    The matrix corresponds to the equations \(x + 2z = 1\) and \(y - z = 3\text{.}\) Solving gives \(x = 1 - 2z\) and \(y = 3 + z\text{.}\)
    🔗
    Since \(z\) is free, the solutions form a line in \(\mathbb{R}^3\text{.}\)
    🔗
    🔗
    🔗
    16.
    The reduced row echelon form of an augmented matrix is
    \begin{equation*} \left[ \begin{array}{ccc\amp c} 1 \amp 0 \amp 2 \amp 3 \\ 0 \amp 1 \amp -1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \end{array} \right]. \end{equation*}
    🔗
    Identify the pivot positions and determine which variables are free.
    🔗
    Hint.
    Pivot positions correspond to leading 1s in the matrix.
    🔗
    🔗
    Answer.
    The pivot positions are in columns 1 and 2, and the third variable is free.
    🔗
    🔗
    Solution.
    The leading 1s occur in the first and second columns, so those columns contain pivot positions. The third column does not contain a pivot, so the corresponding variable is free.
    🔗
    🔗
    🔗
    17.
    Consider the augmented matrix
    \begin{equation*} \left[ \begin{array}{ccc\amp c} 1 \amp 2 \amp -1 \amp 4 \\ 0 \amp 0 \amp 0 \amp 1 \end{array} \right]. \end{equation*}
    🔗
    Is the corresponding linear system consistent? Explain your answer.
    🔗
    Hint.
    Look for a pivot in the last column.
    🔗
    🔗
    Answer.
    The system is inconsistent.
    🔗
    🔗
    Solution.
    The second row corresponds to the equation \(0 = 1\text{,}\) which is impossible. This occurs because there is a pivot in the last column. Therefore, the system is inconsistent and has no solutions.
    🔗
    🔗
    🔗
    18.
    The row echelon form of a system is
    \begin{equation*} \left[ \begin{array}{ccc\amp c} 1 \amp -1 \amp 2 \amp 0 \\ 0 \amp 0 \amp 1 \amp 3 \end{array} \right]. \end{equation*}
    🔗
    Does the system have infinitely many solutions? If so, explain why.
    🔗
    Hint.
    Determine whether every variable corresponds to a pivot column.
    🔗
    🔗
    Answer.
    Yes, the system has infinitely many solutions.
    🔗
    🔗
    Solution.
    There are three variables but only two pivot columns. Since at least one variable is free, the system has infinitely many solutions.
    🔗
    🔗
    🔗
    19.
    A system of linear equations in three variables has a reduced row echelon form with exactly two pivot positions.
    🔗
    Describe the solution set geometrically.
    🔗
    Hint.
    Think about how many free variables there are.
    🔗
    🔗
    Answer.
    The solution set is a line in three‑dimensional space.
    🔗
    🔗
    Solution.
    With three variables and two pivot positions, there is one free variable. Therefore, the solution set depends on one parameter and forms a line in \(\mathbb{R}^3\text{.}\)
    🔗
    🔗
    🔗
    20.
    Explain why the number of pivot positions in the reduced row echelon form of an augmented matrix determines whether a system has no solutions, exactly one solution, or infinitely many solutions.
    🔗
    Hint.
    Consider the roles of pivots in the coefficient columns and the last column.
    🔗
    🔗
    Answer.
    Pivot positions determine consistency and the number of free variables.
    🔗
    🔗
    Solution.
    If there is a pivot in the last column, the system is inconsistent and has no solutions. If every variable column has a pivot, there are no free variables and the system has exactly one solution. If there are fewer pivot positions than variables and no pivot in the last column, there are free variables and infinitely many solutions.
